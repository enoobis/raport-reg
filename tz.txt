тз: raport-reg

цель
сайт для регистрации студентов на рапорты / мероприятия.
админ создаёт мероприятия, студенты оставляют заявки,
админ выгружает список в txt.

роли
- студент — видит открытые мероприятия и регистрируется
- админ — создаёт / меняет / архивирует мероприятия,
  смотрит заявки, ищет, выгружает txt

публичная часть
- заголовок: регистрация на рапорт
- список только открытых мероприятий (кнопки)
- форма записи, все поля обязательные:
  фио, группа, телефон, название проекта, описание проекта
- нельзя зарегистрировать то же фио повторно на одно мероприятие
- после конца регистрации мероприятие уходит в архив
  и скрывается с главной

панель (/panel.html, пароль admin)
- вход по паролю
- создать мероприятие: название + дата конца регистрации
- изменить: название, дату (можно продлить и снова открыть)
- вручную отправить в архив
- список заявок с поиском
- выгрузка .txt по выбранному мероприятию

формат txt
//фио//группа//телефон//проект//описание//

стек
- backend: node.js + express
- db: sqlite (node:sqlite, нужен node 24+)
- frontend: html / css / js
- стиль: контрастный сайт 2000-х

хранение
data/raports.db — таблицы events, regs

запуск
npm install
PORT=80 npm start

вне скоупа
регистрация пользователей, роли в бд, почта/смс,
https/домен, мобильное приложение.
